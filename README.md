# NEX - 47 CATALYS'S | Digital Marketing Agency Web Portal

A high-converting, cyberpunk-modern performance marketing agency website built for **NEX - 47 CATALYS'S**, styled to match the official brand logo with vivid cyber neon green accents and deep obsidian blacks.

## 🚀 Live Preview
Open `index.html` in any modern web browser or run a local web server:

```powershell
# Using Python
python -m http.server 8000

# Using Node / npx
npx serve .
```
